Скрипт на PowerShell для автоматизации администрирования серверов и рабочих станций под управлением ОС Windows. Предназначен для автоматической очистки дисков, создания локальных пользователей с безопасными паролями и анализа журнала событий безопасности.

	Основные возможности
Управление пользователями: Создание локальных учетных записей, привязка к группам (например, Administrators или Remote Desktop Users), генерация случайных 16-значных паролей и установка флага принудительной смены пароля при первом входе.

Обслуживание дисков: Удаление временных файлов системных и пользовательских директорий, очистка корзины, очистка кэша службы Windows Update (SoftwareDistribution).

Анализ безопасности: Парсинг событий безопасности Event Log (Event ID 4625 — Failed Logon) для выявления брутфорс-атак по RDP или локальной сети с выводом топ-IP адресов и атакуемых логинов.

	Инструкция по запуску
Важно: Скрипт должен запускаться в консоли PowerShell, открытой от имени Администратора.

1. Настройка политики выполнения скриптов (при необходимости):

PowerShell
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process
2. Автоматическая очистка диска:

PowerShell
.\WinAdminTool.ps1 -CleanDisk
3. Создание пользователя с добавлением в группу:

PowerShell
.\WinAdminTool.ps1 -CreateUser -Username "support_user" -Group "Remote Desktop Users"
4. Анализ неудачных попыток входа (Security Log):

PowerShell
.\WinAdminTool.ps1 -ParseLogs
	Настройка автоматического запуска (Windows Task Scheduler)

Для регулярной автоматической очистки системы создайте задачу в Планировщике задач Windows:

Откройте Планировщик задач (taskschd.msc).

Нажмите Создать простую задачу...

Задайте триггер (например, Еженедельно в воскресенье в 03:00).

В действии выберите Запустить программу:

Программа или сценарий: powershell.exe

Добавить аргументы: -ExecutionPolicy Bypass -File "C:\Scripts\WinAdminTool.ps1" -CleanDisk

В свойствах задачи поставьте галочку Выполнять с наивысшими правами.
